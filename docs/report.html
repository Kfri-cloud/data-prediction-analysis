데이터예측분석

뉴스가 미래 예측에 도움이 되는지, 시간순 비교실험으로 검증합니다.

판정: 조건부 가능성은 확인. 서울 소상공인 현재 예측의 타당성은 아직 미확인.
다른 분야의 개선 사례는 연구를 시작할 근거다. 우리 대상에서의 시간순 검증과 실제 미래 기록이 있어야 적용 근거가 된다. 아래 1~6절은 초기 문헌 감사 기록이며, 후속 탐색 실험 결과는 별도 링크와 하단에 추가했다.

후속 실행 결과: 시간순 47개 시점 비교 — 뉴스 추가 시 평균 오차 5.07% 증가
공개시점 입증이 미완료인 탐색 실험이며, 서울 소상공인 적용의 타당성은 미확인이다.

1. 무엇을 입증해야 하는가

검증할 가설은 “같은 시점에 이용 가능한 숫자 정보가 같을 때, 뉴스를 추가한 예측이 이후 실제 결과를 더 잘 예측한다”이다. 뉴스가 변화를 일으켰다는 인과관계와 현재에도 반드시 통한다는 주장은 별개다.

더 오래된 기간으로 학습 → 이후 과거 구간 예측 → 여러 시작점에서 반복 → 마지막 보류 구간 확인 → 현재 예측을 미리 저장 → 새 결과와 비교

앞 단계가 반복 통과하면 현재 적용을 지지하는 경험적 근거가 생긴다. 그 근거는 데이터 수집 방식·뉴스의 의미·경제 환경·대상 업종이 충분히 유사하다는 조건을 가진다. 과거 성능만으로 “현재 타당할 확률 90%”를 산출할 수는 없다.

5. 우리 대상에 적용할 검증 설계

  1. 자료 자격: 기사 공개시각, 사건시각, 원본 버전과 통계 발표시각·당시 수치를 연결한다. 발표 전 수치와 나중에 수정된 기사 내용을 차단한다.
  2. 동일 조건 비교: 계절 기준선, 숫자만, 숫자+뉴스, 숫자+기사량, 숫자+오래된 뉴스 대조군을 비교한다. 같은 숫자 정보·학습 예산을 준다.
  3. 대과거 → 과거: 학습 구간을 앞으로 이동하며 반복 검증한다. 검증 결과로 정한 모형은 마지막 보류 구간에서 한 번 확인한다.
  4. 판정: 주 지표는 MAE 차이다. 제안한 실용 기준은 5% 개선이며 보편적 통계 법칙이 아니다. 같은 예측시점의 지역들을 묶은 시간 블록 분석으로 불확실성을 평가한다. 우연한 승리와 다중비교를 통제한다.
  5. 확률·경고: 변화량 오차 개선과 “하락 확률 70%”의 타당성은 다른 검증이다. 확률을 내면 Brier 점수·보정 정도와 거짓 경고를 따로 평가한다.
  6. 현재 검증: 예측값과 모델을 결과 발표 전에 고정·저장한다. 실제 결과가 쌓이면 비교한다. 성능이 달라지면 현재 경고를 재검토한다.

서울 분기 자료는 독립적인 시간 표본 수가 적을 수 있다. 자치구 수를 곱해 시간 증거가 충분하다고 판단하지 않는다. 최초 제안 대상은 다음 분기의 추정매출 변화이며 개별 가게 폐업확률은 아니다. 정확한 업종·집계식·날짜 경계는 실제 자료 감사 후, 모델 성능을 보기 전에 확정한다.

모델 실행 전 작성한 검증 프로토콜

6. 초기 문헌 감사 시점의 실행 기록

실행 완료: 논문 원문 확인, 고정 버전 데이터 다운로드와 해시 검증, CSV 시간정보 감사, TimesX 표 자동 추출·재계산, 시간정보 차단 테스트 10개 통과.
초기 감사 당시 미실행: 예측 모델 학습, 한국 자료 백테스트, 현재 실시간 예측, 3D 경고 화면. 후속 작업에서 원·달러 탐색 모델은 실행했으며, 서울 매출 검증·현재 실시간 예측·3D 경고는 여전히 미실행이다.

다음 실험에 필요한 것은 공개시점과 과거 수치 버전을 입증할 수 있는 대상 자료다. 이를 확보한 뒤 숫자만 쓴 기준선과 뉴스 추가 모델을 동일 조건에서 비교한다. 조건이 충족되지 않으면 “성능이 좋아 보이는 결과”를 입증 자료로 제출하지 않는다.

검토 방식: evaluate 스킬의 대체 경로로 기계적 확인과 의미 검토를 수행했다. Ouroboros 평가 서버의 승인이나 다중모델 합의는 실행하지 않았다. 테스트 통과는 감사 코드 동작에 관한 결과이며 예측 타당성 승인이 아니다.

47개 예측 시점 전체에서 평균 절대오차가 5.07% 증가했다. 공개시점 검증도 미완료이므로 정식 타당성 검증 통과가 아니다.

저자 공식 TimesX 데이터의 원·달러 환율을 사용했다. 한국과 관련된 수치라는 이유로 성능 확인 전에 선택했다. 원래 목표인 서울 소상공인 매출·폐업 검증을 대체하지 않는다. 2023년 2월~2026년 3월 66개 입력에서, 앞선 구간으로 학습하고 2024년 이후 47개 시점의 다음 12개 영업일 평균 환율 변화율을 예측했다. 목표는 100 × (미래 12개 값의 평균 / 마지막 과거 값 − 1)이다.

MAE 단위는 변화율의 퍼센트포인트(pp). 작을수록 좋다. 2026년에는 관측이 4개뿐이어서 확인용 근거가 부족하다. 이 수치를 현재 예측의 성공확률로 해석할 수 없다.

2024년의 미세한 개선은 2025년에 유지되지 않았다. 전체 오차 차이(기본−뉴스)는 −0.0403pp이고, 탐색용 시간 블록 부트스트랩 95% 구간은 −0.0954~+0.0101pp로 0을 포함한다. 표본이 적고 정상성도 보장되지 않으므로 확정적 유의성 판정에 쓰지 않는다. 2026년 4개로 계산된 구간은 특히 신뢰하기 어렵다.

사건 건수만 추가한 모델과 오래된 사건을 넣은 모델도 비교했다. 뉴스 추가 모델은 이 대조군과 변화 없음 기준선보다 오차가 컸다. 전체 방향 적중률은 기본 59.6%, 뉴스 추가 63.8%였지만, 사전에 정한 주평가지표는 변화량의 MAE다. 방향 지표만 골라 성공으로 판정하지 않는다. 변화 없음 기준선의 방향값은 중립이어서 상승·하락 적중률 비교에 적합하지 않다.

미래를 보지 않도록 실행에서 통제한 것

각 시점에서는 목표 구간이 이미 끝난 앞선 샘플만 학습에 사용했다. 모델은 고정된 릿지 회귀이고, 숫자·달력·다른 환율 정보는 모든 비교군에 동일하게 제공했다. 뉴스는 사전학습 AI 없이 단어 해시 32개와 사건 건수로 변환했다. 특징 표준화는 학습 구간에만 맞췄다. 모델·설정·데이터 해시를 최초 실행 전에 저장했고 성능을 본 뒤 조정하지 않았다. 마지막 구간도 시간순으로 평가하며, 관측된 앞선 결과만 이후 시점 학습에 편입하는 방식이다.

여전히 통제하지 못한 것
