키워드 중심 추가 실험

결론: 기존 단어 해시보다 개선됐지만, 숫자 기준선을 넘는 추가 효과는 확인되지 않았다.
전체 47개 시점에서 키워드 모델의 평균 절대오차는 숫자 기준선보다 0.32% 컸다. 정식 타당성은 여전히 미입증이다.

기존 B2는 전체 맥락을 이해하는 모델이 아니라 단어를 32개 해시 특징으로 바꾸는 단순 방식이었다. 따라서 기존 결과로 전체 맥락 모델이 부정확하다고 결론 내릴 수 없다. 이번에는 영어 사건 설명에서 금리정책·물가·고용·경기수요·무역·위험·에너지·환율의 8개 주제에 속하는 표현을 고정 사전으로 추출했다.

예: interest rates, FOMC → 금리정책, inflation, CPI → 물가, tariffs, exports → 무역. 단어 경계를 검사하고 긴 구문을 우선 매칭하며, 주제별 언급 횟수를 1,000단어당 빈도로 정규화했다. 정답을 보고 키워드를 선별하지 않았고 이번 결과를 본 뒤 사전을 바꾸지 않았다.

MAE는 작을수록 좋고 증감이 음수이면 개선이다. ‘기본’은 숫자·달력·관련 환율 지표다. 키워드 모델도 동일한 숫자 입력을 사용하며, 텍스트 부분만 키워드로 표현한다. 전체 맥락 언어모델은 실행하지 않았다.

키워드의 전체 오차 차이(기본−키워드)는 −0.00253pp, 설명용 블록 부트스트랩 95% 구간은 −0.04776~+0.05300pp로 0을 포함한다. 방향 적중률은 기본 28/47회에서 키워드 31/47회로 높아졌지만, 이를 현재 성공확률 66%로 해석하지 않는다. 변화량 예측은 사전에 정한 주평가지표이며 방향만 골라 성공으로 판정하지 않는다.

해석의 범위

기존 실험 결과를 확인한 뒤 사용자의 요청으로 추가한 비교다. 2026년 구간도 이번 방법에 대해서는 새로운 보류 구간이 아니다. 47개 시점을 재사용한 탐색 결과이며 다중 비교를 거친 확증 실험이 아니다. 새 미사용 데이터와 공개시점이 검증된 자료가 필요하다. 2026년은 4개뿐이므로 부트스트랩 구간도 확정적 판단에 쓰지 않는다.

사전은 주제만 표현한다. 예를 들어 ‘inflation is rising’과 ‘inflation is falling’은 동일한 물가 빈도를 만든다. 부정문, 변화 방향, 예상 대비 충격, 어느 나라의 정책인지, 실제 발표인지 전망인지까지는 해석하지 못한다. 이 키워드 실험 이후 ‘주제 + 상승/하락 + 발표 주체 + 예상 대비 차이’를 분리하는 후속 실험을 실행했다. 후속 사건 특징 결과 보기.

같은 학습 구간·회귀 모델·정규화·평가 시점을 유지했고 기존 기본 예측 47개가 재계산 결과와 일치하는지 확인했다. 기사별 공개시각·원문 스냅샷 부재와 서울 소상공인에 대한 외적 타당성 문제는 그대로 남는다.
