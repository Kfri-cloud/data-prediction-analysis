금·은을 포함한 기존 상품 10개에 동일한 절차를 적용했습니다. 나스닥에 집중하는 지수 측 예측과 실제 발표·발생 결과 표현에 집중하는 뉴스 측 예측을 만든 뒤, 최종 비중은 50:50으로 유지했습니다. 금·은은 예측 대상이며 추가 입력으로 넣은 것은 아닙니다. 나스닥은 직접적인 대중심리 지수가 아닙니다.

계산 방법

지수 쪽 = a×(B1+나스닥 모델) + (1−a)×(B1+S&P 500·KOSPI·KOSDAQ 모델). 뉴스 쪽 = b×(B1+결과형 뉴스 모델) + (1−b)×(B1+나머지 뉴스 모델). 최종 = 지수 쪽×0.5 + 뉴스 쪽×0.5.

a와 b는 50%, 75%, 100% 중 각각 선택했습니다. 예측 시점보다 먼저 결과가 확정된 과거 예측 8회 이상에서 MAE가 가장 작은 비중을 고릅니다. 과거 예측도 해당 시점 이전 자료로만 학습합니다. 부족하면 50%로 시작합니다. 비교군은 0%, 25%도 허용합니다. 각 예측 시점마다 다시 선택하며 상품별로 별도 학습합니다.

결과형 문장은 reported·released·approved·rose·fell 같은 표현을 포함하고 예상·부정 표현을 제외한 규칙 기반 후보입니다. 사람의 사실 검증을 거치지 않았고 혼합 문장 누락도 가능합니다. 나머지 문장이 모두 심리 뉴스인 것은 아닙니다. 기존 숫자 기준선과 뉴스 사전은 유지했습니다.
