기존 결과를 바탕으로 구성한 후보 조합

이번 후보 중 전체 MAE가 가장 낮은 것은 ‘키워드·방향 모델 + 네 지수 모델’의 50:50 예측 혼합이다.
숫자 기준선보다 오차 2.94% 감소. 다만 2025년에는 악화됐고 불확실성 구간이 0을 포함하므로 검증된 모델로 승격하지 않는다.

어떤 결과를 묶었는가

공통 47개 TimesX 예측에서 키워드·방향 모델은 숫자 기준선 대비 오차 0.53% 감소, 네 지수 모델은 0.29% 감소였다. 이를 약한 후보 신호로 삼아 조합을 고정했다. 10개년·월별 실험의 점수는 데이터 출처와 기준 입력이 달라 섞지 않았다. 그 실험에서 드러난 불안정성은 조합의 적용을 서두르지 않을 근거로 유지했다.

세 조합은 이번 결과를 보기 전에 고정했다. ① 두 모델의 예측값을 50:50 평균, ② 숫자·지수·키워드·방향을 하나의 회귀 모델에 입력, ③ 숫자·지수·방향만 넣는 간소 모델이다. 국가·주체·예상 차이와 일반 단어 해시는 제외했다. 이 선택 자체가 이전 결과를 보고 이루어졌다는 사실을 기록했다.

혼합 모델은 전체에서 두 개별 모델보다 오차가 작았지만, 2026년 4개 구간에서는 지수 모델 단독보다 나빴다. 숫자 기준선과의 MAE 차이는 +0.02341pp, 설명용 95% 시간 블록 부트스트랩 구간은 −0.05722~+0.09756pp다. 0을 포함하므로 안정적인 개선을 입증하지 못했다. 개별 구성 모델과의 차이 구간도 모두 0을 포함한다.

혼합 모델의 방향 적중은 29/47회(61.7%)로 숫자 기준선 28/47회보다 1회 많았지만, 키워드·방향 모델의 31/47회보다 적었다. 변화량 오차의 개선을 방향 예측이나 보정된 성공확률의 개선으로 바꾸어 해석하지 않는다.

현재 연구 우선순위

  1. 다음 독립 검증의 첫 후보: 고정 50:50 혼합. 이번 공통 자료에서 가장 낮은 오차를 냈고 별도 가중치 탐색이 없다.
  2. 보조 후보: 지수·방향 간소 조합. 전체 오차는 1.97% 감소했으나 2025년에는 5.59% 악화됐다. 최근 4개만 보고 우승 모델로 선택하지 않는다.
  3. 우선순위 낮음: 모든 입력을 한 모델에 통합. 전체 개선 0.09%로 작았고 2025년에 8.43% 악화됐다.

이 순위는 같은 자료를 반복 탐색한 연구 우선순위이며 실제 운영 추천이 아니다. 원래 제안한 5% 실용 개선 기준에도 혼합 모델은 못 미쳤다. 현재부터 입력과 예측을 고정 저장한 새 기간 검증 또는 아직 쓰지 않은 자료가 필요하다. 이번에는 실시간 예측·자동 경고를 발행하지 않았다.

검증 범위

날짜·정답·기본 예측·학습 수가 맞는지 확인해 47개를 연결했고, 두 구성 모델을 다시 학습해 기존 예측과 일치함을 확인했다. 학습 구간, 규칙 기반 방향 추출, 지수 48시간 지연 규칙, 회귀 설정은 변경하지 않았다. 기존 데이터의 원문·공개시각·수치 버전 미확인 문제는 그대로다. 2026년 구간도 이미 본 자료라 새로운 보류 구간이 아니다.
